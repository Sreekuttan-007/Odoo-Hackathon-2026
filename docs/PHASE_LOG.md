## Phase 10: Payloom Intelligence — Grounded AI Payroll Briefing
- **Status**: DONE
- **Requirements**: A grounded AI layer that turns verified payroll facts into a concise, source-linked operational brief. Not a chatbot. AI may explain / summarise / prioritise / communicate; AI may **never** calculate or modify payroll, invent numbers or risks, or change a severity. If AI disagrees with Payloom, Payloom wins. If AI fails, Payloom still works.
- **Architecture** (`app/services/intelligence.py`): deterministic **evidence builder** → **source registry** → provider call → **claim validation** → brief.
  - `build_brief_evidence(db, payrun, simulator_scenario=None)` — reuses `preflight.run_preflight` verbatim for findings (never re-derives severity), sums payrun totals with `Decimal`, and emits a `sources` list where every citable fact has a stable `id`, a backend-owned `severity`, a pre-computed number, and (where a real route exists) a deep link. Sanitises employee names → codes; strips anything matching a secret/contact pattern. `fingerprint` = sha256 of the canonical evidence (16 hex).
  - Provider: `app/services/ai_provider.py` — a single pluggable LLM provider (`AI_PROVIDER` = `gemini` (default, `GEMINI_API_KEY`, `gemini-2.5-flash`) | `anthropic` (`ANTHROPIC_API_KEY`, Claude Haiku)) shared by both this brief and the Phase 7B narrator. **One provider at a time — no duplicate stacks.** `ProviderError(reason)` on any failure; strict system prompt (10 rules), structured-JSON-only output.
  - `_validate_items()` — the grounding gate: drop any item citing an unknown id or no id; normalise `priority` to the deterministic max severity of the cited sources (AI can't upgrade WARNING→BLOCKER); reject any item whose ₹-figure doesn't appear verbatim in a cited source or the totals.
  - `run()` never raises. No key / timeout / 4xx / 5xx / malformed JSON → `_build_response(ai=None)`: a **backend-generated deterministic fallback** brief (attention items straight from Preflight, labelled "not AI-generated"). `deterministic_summary()` is always present regardless.
- **API**: `POST /api/payroll/payruns/{payrun_id}/intelligence/brief` — RBAC `get_current_payroll_operator` (`HR_PAYROLL_USER`/`HR_PAYROLL_MANAGER`/`ADMIN`; `EMPLOYEE`, `HR_MANAGER` → `403`). Optional body `{ "simulator_scenario": {...} }` passes through a just-run (ephemeral) Simulator scenario — never stored. DRAFT payrun → `available:false, reason:NOT_COMPUTED`. Persists nothing; effectively read-only.
- **Frontend**: `components/PayrollBrief.tsx` on the Payrun detail page (`pages/PayrunDetail.tsx`), below Preflight. "Generate Payroll Brief" → headline, summary, Needs Attention (severity chip + `Source: Preflight · CODE · EMP-xxxx` deep link), Observations, Suggested Review Order, expandable Sources, visible AI disclosure. Unavailable → restrained banner + Regenerate. Payslip-level "Explain in Simple Language" (the Phase 7B narrator on `/payroll/payslips/:id/trace`) is the PayTrace-side companion — unchanged.
- **Schemas**: `app/schemas/intelligence.py` — `BriefSource`, `BriefItem`, `PayrollBriefResponse`.
- **Config**: `AI_PROVIDER` (default `"gemini"`) + `GEMINI_API_KEY` added alongside the existing optional `ANTHROPIC_API_KEY`. `.env.example` updated with placeholders.
- **Tests**: `tests/test_intelligence.py` — 18 tests, provider always mocked (both the Gemini and Anthropic wire formats): evidence privacy (asserts no bank/id/contact/secret and no employee name in the packet JSON), fingerprint determinism, no-key/NOT_COMPUTED fallback, valid grounded brief, unknown-source drop, no-source drop, severity-tampering normalisation, numeric-hallucination drop, timeout/500/malformed fallback (parametrised), EMPLOYEE 403, HR_MANAGER 403, HR_PAYROLL_USER 200, **DB non-mutation** (snapshot rules/payruns/payslips/lines/contracts before & after 3 brief calls — byte-identical), and a full DRAFT→…→PAID regression with the brief called at each step. All 200 backend tests pass; `tsc -b` + `vite build` clean.
- **Migration**: none — Payloom Intelligence persists nothing.
- **Deferred (explicitly, per spec)**: brief persistence/caching (generation is ephemeral; a fingerprint is returned for the client to detect staleness but no server-side cache was added — "do not add persistence merely for AI"), an Employee-facing brief endpoint (the Payslip narrator already covers the employee explanation need), and any confidence score / recommendation engine / legal-tax interpretation (prohibited).
